# WADP-L4 Demonstration-3 [Blog-Management-System]
# 📝 Django Blog Application

A simple and user-friendly **Blog Web Application** built with **Python and Django**.  
This project allows users to manage blog posts with categories, authors, content, images, and publishing dates.

## 🚀 Features

- 🔐 Custom User Authentication
- 👤 User Profile with Full Name
- 📝 Create and manage blog posts
- 📚 Blog categories:
  - Educational
  - Technologies
  - Sports
- 🖼️ Blog image upload
- ✍️ Author name management
- 📅 Publish date
- 🕒 Automatic creation date
- 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

- **Python**
- **Django**
- **HTML5**
- **CSS3**
- **Bootstrap**
- **SQLite**
- **Pillow**
